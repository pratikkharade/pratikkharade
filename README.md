## Featured Work

### Sage–NDP Scientific Data Workflows

An exploration of a conversational interface connecting the **Sage edge-computing ecosystem** with the **National Data Platform** and scientific streaming infrastructure.

The project extends the Sage MCP workflow beyond data discovery and querying. It introduces tools for registering scientific datasets, preserving provenance, reviewing metadata, publishing resources, and creating filtered streams from live Sage observations.

**Highlights**

- Natural-language access to distributed sensors and edge resources
- Dataset registration and publication through NDP
- Automatic capture of source queries, time ranges, nodes, and plugins
- Reviewable metadata and confirmation-based publishing
- Filtered Kafka streams derived from live Sage data
- Stream profiling, sampling, tailing, and lifecycle management

**Technologies:** Python · Model Context Protocol · FastMCP · Kafka · Sage · NDP · Scientific data catalogs

[Project overview →](https://github.com/pratikkharade/sage-summer-camp-2026)  
[Sage MCP repository →](https://github.com/pratikkharade/ndp-sage-mcp)

### Movie Sentiment Analysis

An experimental comparison of machine-learning approaches for classifying sentiment in movie-related text.

The project evaluates combinations of RoBERTa representations, TF–IDF features, spaCy processing, averaged perceptrons, logistic regression, support vector machines, boosting, and voting classifiers.

**Technologies:** Python · RoBERTa · TF–IDF · spaCy · scikit-learn · NLP
